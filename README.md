# Branch Messenger

Mac용 Instagram·WhatsApp 통합 메신저의 정식 설치파일과 자동 업데이트를 배포하는 저장소입니다.

- macOS 13 이상 / Apple Silicon
- [Releases에서 설치파일 확인](https://github.com/devsehyeon/branch-messenger-releases/releases)
- 정식 설치본은 Developer ID 서명과 Apple 공증을 거칩니다.
- 설치 후 앱의 **Branch Messenger → 업데이트 확인…**에서 새 버전을 확인할 수 있습니다.
- 기존 개발용 설치본(0.1.5)은 첫 정식 DMG를 직접 설치해야 합니다.

이 저장소에는 설치파일·변경 사항·체크섬만 게시합니다. 앱 소스와 서버 설정은 비공개 저장소에서 관리합니다.
