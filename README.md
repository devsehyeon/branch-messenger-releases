# Xessenger

Instagram·WhatsApp 대화를 한곳에서 관리하는 Xessenger의 정식 Mac 설치파일과 자동 업데이트를 배포하는 저장소입니다.

**[최신 Mac 설치파일 다운로드](https://github.com/devsehyeon/xessenger-releases/releases/latest)**

- macOS 13 이상 · Apple Silicon
- 정식 설치파일은 Developer ID 서명과 Apple 공증을 거칩니다.
- DMG를 열고 **Xessenger를 응용 프로그램 폴더로 옮긴 뒤** 실행하세요.
- 앱의 **Xessenger → 업데이트 확인…**에서 새 버전을 받을 수 있습니다. 이전 이름의 앱에서는 **Branch Messenger → 업데이트 확인…**을 선택하세요.
- 앱에 새 버전이 감지되면 왼쪽 하단 프로필 위에도 업데이트 버튼이 표시됩니다.
- 기존 Branch Messenger 계정과 대화는 계속 사용할 수 있습니다. 과거 릴리스 파일은 업데이트 호환과 기록을 위해 보존합니다.

`xessenger.com`은 향후 서비스 소개페이지용 도메인입니다. 현재 API 서버는 `api.xessenger.com`에서 운영합니다.

이 저장소에는 설치파일·변경 사항·체크섬만 게시합니다. 앱 소스와 서버 설정은 비공개 저장소에서 관리합니다.
